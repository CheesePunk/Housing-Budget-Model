# Инструкция по эксплуатации `housing_budget_model.py`

Это практическое руководство: как установить, запустить и настроить
программу под свои данные. Никаких формул — только действия и результат.

Если нужна теория и обоснование модели — см. `ARTICLE.md`.
Если нужен обзор проекта — см. `README.md`.

---

## 1. Что делает программа

`housing_budget_model.py` — консольная программа на Python, которая:

1. Считает бюджет домохозяйства, покупающего студию 24 м² (площадь
   можно изменить).
2. Проверяет, устойчив ли бюджет: доля платежей по ипотеке и содержанию
   не превышает порог, резерв на ремонт сформирован.
3. Прогоняет Монте-Карло по случайному доходу и цене м² и показывает,
   как часто бюджет «ломается».
4. Сравнивает **покупку** и **аренду** на одних и тех же шоках дохода
   и цены.
5. Находит **точку безубыточности**: при какой доходности инвестиций
   арендатор догоняет покупателя по деньгам и по полезности.
6. Строит **тепловую карту** чувствительности к ставке и цене м²
   и **срез** по ставке аренды.

Результаты сохраняются в папку `output/`: PNG-графики, CSV-таблицы,
NPZ с сырыми массивами.

## 2. Установка

### 2.1. Что нужно

- Python 3.10 или новее.
- Библиотеки: `numpy`, `pandas`, `matplotlib`, `scipy`.

### 2.2. Установка библиотек

Открой терминал (командную строку) и выполни:

```bash
pip install numpy pandas matplotlib scipy
```

Если `pip` не найден — попробуй `pip3` или `python -m pip`.

### 2.3. Проверка

```bash
python --version
```

Должно показать `Python 3.10.x` или новее.

## 3. Первый запуск

1. Положи файл `housing_budget_model.py` в любую папку, например `~/projects/housing_budget_model`.
2. Открой терминал и перейди в эту папку:

   ```bash
   cd ~/projects/housing_budget_model
   ```

3. Запусти программу в режиме «всё сразу» с базовыми параметрами:

   ```bash
   python housing_budget_model.py --mode all --out output --n-paths 300 --seed 42
   ```

4. Дождись окончания (обычно 1–3 минуты). В папке `output/` появятся:

   | Файл | Что это |
   |---|---|
   | `01_basic_path.png` | график базового сценария |
   | `02_mc.png` | гистограммы Монте-Карло |
   | `02_mc_stats.npz` | сырые массивы Монте-Карло |
   | `03_buy_vs_rent.png` | сравнение покупки и аренды |
   | `03_compare_stats.npz` | сырые массивы сравнения |
   | `04_breakeven.csv` | точка безубыточности |
   | `05_breakeven_grid.png` | тепловая карта по ставке и цене |
   | `05_breakeven_grid.csv` | таблица тепловой карты |
   | `06_breakeven_vs_rent.png` | срез по ставке аренды |
   | `06_breakeven_vs_rent.csv` | таблица среза |
   | `06_summary.csv` | сводка ключевых метрик |

5. Открой PNG-файлы любым просмотрщиком картинок, CSV — в Excel,
   LibreOffice или Google Sheets.

## 4. Как подставить свои значения

Все параметры задаются **флагами в командной строке**. Ничего в коде
менять не нужно.

### 4.1. Главные флаги

| Флаг | Что означает | Пример |
|---|---|---|
| `--area` | площадь квартиры, м² | `--area 24` |
| `--price-m2` | цена квадратного метра, ₽ | `--price-m2 120000` |
| `--down-payment` | доля первоначального взноса (0…1) | `--down-payment 0.20` |
| `--rate` | годовая ставка ипотеки (0…1) | `--rate 0.12` |
| `--years` | срок ипотеки, лет | `--years 20` |
| `--income` | доход, ₽/мес | `--income 80000` |
| `--maintenance` | расходы на содержание, ₽/мес | `--maintenance 7000` |
| `--theta` | порог доли платежей в доходе (0…1) | `--theta 0.45` |
| `--rent-m2` | аренда, ₽/м²/мес | `--rent-m2 700` |
| `--rent-inflation` | годовой рост аренды (0…1) | `--rent-inflation 0.06` |
| `--investment-rate` | годовая доходность инвестиций (0…1) | `--investment-rate 0.08` |
| `--price-mode` | как меняется цена м²: `deterministic` или `stochastic` | `--price-mode deterministic` |
| `--n-paths` | сколько траекторий Монте-Карло | `--n-paths 300` |
| `--seed` | зерно случайности (для воспроизводимости) | `--seed 42` |
| `--out` | папка для результатов | `--out output` |

### 4.2. Как вписать свои числа — пример

Допустим, ты смотришь студию 28 м² в своём городе:

- цена м² — 95 000 ₽;
- взнос — 15 %;
- ставка — 17 % годовых;
- срок — 25 лет;
- доход — 95 000 ₽/мес;
- содержание — 8 000 ₽/мес;
- аренда похожей студии — 850 ₽/м²/мес;
- доходность инвестиций (депозит) — 14 % годовых.

Команда:

```bash
python housing_budget_model.py --mode all --out my_case --area 28 --price-m2 95000 --down-payment 0.15 --rate 0.17 --years 25 --income 95000 --maintenance 8000 --rent-m2 850 --rent-inflation 0.07 --investment-rate 0.14 --n-paths 500 --seed 7
```

Результаты будут в папке `my_case/`.

### 4.3. Важные правила

- **Доли и проценты — в долях, не в процентах.** Ставка 12 % → `--rate 0.12`,
  а не `12`. Взнос 20 % → `--down-payment 0.20`.
- **Доход и расходы — в рублях в месяц.** Не в тысячах.
- **`--area` и `--price-m2`** можно менять независимо: программа считает
  цену как `area × price-m2`.
- **`--seed`** фиксирует случайность. При одном и том же `seed`
  и одинаковых параметрах результаты совпадут. Если хочешь «другую
  случайную вселенную» — поменяй `seed`.

## 5. Режимы работы (`--mode`)

Можно запускать не всё сразу, а только нужный блок.

| Режим | Что считает | Когда использовать |
|---|---|---|
| `basic` | базовую траекторию покупки | быстро проверить устойчивость |
| `mc` | Монте-Карло по доходу | оценить вероятности «прорывов» |
| `compare` | покупка vs аренда | сравнить альтернативы |
| `breakeven` | точки `r_inv*` и `r_inv**` | узнать порог доходности |
| `grid` | тепловую карту по ставке и цене | увидеть чувствительность |
| `rent-sensitivity` | срез по ставке аренды | как аренда влияет на порог |
| `all` | всё сразу | полный отчёт |

Примеры:

```bash
# только базовая устойчивость
python housing_budget_model.py --mode basic --out output

# только сравнение покупки и аренды
python housing_budget_model.py --mode compare --out output --n-paths 500

# только точка безубыточности
python housing_budget_model.py --mode breakeven --out output
```

## 6. Что читать в результатах

### 6.1. `06_summary.csv` — сводка

Главный файл для быстрого взгляда. Колонки:

| Колонка | Что означает |
|---|---|
| `section` | блок модели (`basic`, `mc`, `compare`, `breakeven`, `grid`, `rent-sensitivity`) |
| `metric` | название метрики |
| `value` | значение |

Что искать:

- `basic / payment_share_first` — доля `(M+R)/Y` в первый месяц.
  Если больше `--theta`, бюджет неустойчив сразу.
- `mc / p_breach_theta_mean` — средняя доля месяцев с нарушением порога.
  Чем больше, тем чаще бюджет «ломается».
- `mc / p_default_income_mean` — средняя доля месяцев, когда дохода
  не хватает на платежи и минимум на жизнь.
- `compare / wealth_buy_mean` и `compare / wealth_rent_mean` — средние
  итоговые благосостояния. Сравни их.
- `compare / share_buy_richer` — доля траекторий, где покупка богаче
  аренды. Больше 0.5 — покупка чаще выигрывает по деньгам.
- `compare / share_buy_more_utility` — доля траекторий, где покупка
  полезнее. Больше 0.5 — покупка чаще выигрывает по комфорту.
- `breakeven / r_star_wealth_%` — порог доходности инвестиций
  по благосостоянию. Если твоя доступная доходность ниже — покупка
  выгоднее по деньгам.
- `breakeven / r_star_utility_%` — то же по полезности.

### 6.2. `04_breakeven.csv` — точка безубыточности

Одна строка с колонками:

| Колонка | Что означает |
|---|---|
| `W_buy` | среднее благосостояние покупателя, ₽ |
| `U_buy` | средняя полезность покупателя |
| `r_star_wealth_%` | `r_inv*`, % годовых |
| `r_star_utility_%` | `r_inv**`, % годовых |

Если в колонке `None` — в заданном диапазоне (от −5 % до 30 %)
корень не найден: при любых разумных доходностях одна из альтернатив
всегда выигрывает.

### 6.3. `05_breakeven_grid.csv` — тепловая карта

Строки — комбинации «ставка × цена м²». Колонки:

| Колонка | Что означает |
|---|---|
| `rate_%` | ставка ипотеки, % |
| `price_k_rub_m2` | цена м², тыс. ₽ |
| `r_star_wealth_%` | порог по благосостоянию |
| `r_star_utility_%` | порог по полезности |

Ищи строки, где `r_star_wealth_%` ниже твоей доступной доходности —
там аренда выгоднее.

### 6.4. `06_breakeven_vs_rent.csv` — срез по аренде

| Колонка | Что означает |
|---|---|
| `rent_rub_m2` | аренда, ₽/м²/мес |
| `r_star_wealth_%` | порог по благосостоянию |

Видно, как порог падает с ростом аренды.

### 6.5. PNG-графики

- `01_basic_path.png` — 6 графиков базового сценария: доход, цена м²,
  долг и капитал, доля платежей, резерв, накопленная полезность.
  Быстрый визуальный осмотр устойчивости.
- `02_mc.png` — 4 гистограммы Монте-Карло: полезность, капитал,
  доля месяцев с нарушением `θ`, доля месяцев с дефицитом дохода.
- `03_buy_vs_rent.png` — 3 гистограммы: благосостояние, полезность,
  среднее потребление (покупка vs аренда).
- `05_breakeven_grid.png` — тепловая карта `r_inv*` и `r_inv**`
  по ставке и цене.
- `06_breakeven_vs_rent.png` — линия `r_inv*` в зависимости от аренды.

## 7. Типичные сценарии использования

### 7.1. «Стоит ли брать ипотеку под текущую ставку?»

```bash
python housing_budget_model.py --mode basic --out case1 --rate 0.18 --income 90000 --price-m2 120000
```

Открой `case1/01_basic_path.png` и `case1/06_summary.csv`. Смотри
`payment_share_first` и `p_breach_theta_mean`. Если `payment_share_first`
близко к `--theta` или выше — бюджет хрупкий.

### 7.2. «Что выгоднее — купить или снимать?»

```bash
python housing_budget_model.py --mode compare --out case2 --rent-m2 900 --income 90000 --rate 0.14
```

Открой `case2/03_buy_vs_rent.png` и `case2/06_summary.csv`. Сравни
`share_buy_richer` и `share_buy_more_utility`.

### 7.3. «При какой доходности инвестиций аренда догоняет покупку?»

```bash
python housing_budget_model.py --mode breakeven --out case3 --investment-rate 0.10 --rent-m2 800
```

Открой `case3/04_breakeven.csv`. Сравни `r_star_wealth_%` со своей
доступной доходностью.

### 7.4. «Как ставка и цена влияют на порог?»

```bash
python housing_budget_model.py --mode grid --out case4 --n-paths 200
```

Открой `case4/05_breakeven_grid.png` и `case4/05_breakeven_grid.csv`.

### 7.5. «Как аренда влияет на порог?»

```bash
python housing_budget_model.py --mode rent-sensitivity --out case5
```

Открой `case5/06_breakeven_vs_rent.png` и `.csv`.

## 8. Возможные ошибки

### 8.1. `ModuleNotFoundError: No module named 'numpy'`

Не установлены библиотеки. Выполни:

```bash
pip install numpy pandas matplotlib scipy
```

### 8.2. `python: command not found`

Python не установлен или не в PATH. Установи Python 3.10+ с
[python.org](https://www.python.org/downloads/) и перезапусти терминал.

### 8.3. `unrecognized arguments: --rate 12`

Скорее всего, передал проценты вместо долей. Ставка 12 % → `--rate 0.12`.

### 8.4. Графики не открываются

PNG лежат в `--out` (по умолчанию `output/`). Открой папку вручную
или используй:

```bash
# Linux
xdg-open output/01_basic_path.png
# macOS
open output/01_basic_path.png
# Windows
start output\01_basic_path.png
```

### 8.5. Программа работает долго

Уменьши `--n-paths` (например, до 100) или не запускай `--mode all`,
а только нужный блок.

### 8.6. В `04_breakeven.csv` стоит `None`

В диапазоне доходностей от −5 % до 30 % корень не найден. Это нормально:
при данных параметрах одна из альтернатив выигрывает при любой
разумной доходности. Смотри графики `03_buy_vs_rent.png` и
`06_summary.csv`.

### 8.7. Хочу другой диапазон поиска точки безубыточности

По умолчанию поиск идёт от −5 % до 30 % годовых. Если нужно шире —
это правится в коде: в `breakeven_investment_rate` и
`breakeven_vs_rent` параметры `r_lo` и `r_hi`. Открой файл и замени
значения.

## 9. Мини-шпаргалка

```bash
# Полный прогон с базовыми параметрами
python housing_budget_model.py --mode all --out output --n-paths 300 --seed 42

# Свои параметры
python housing_budget_model.py --mode all --out my_case --area 28 --price-m2 95000 --down-payment 0.15 --rate 0.17 --years 25 --income 95000 --maintenance 8000 --rent-m2 850 --rent-inflation 0.07 --investment-rate 0.14 --n-paths 500 --seed 7

# Только устойчивость
python housing_budget_model.py --mode basic --out case1

# Только покупка vs аренда
python housing_budget_model.py --mode compare --out case2

# Только точка безубыточности
python housing_budget_model.py --mode breakeven --out case3

# Только тепловая карта
python housing_budget_model.py --mode grid --out case4

# Только срез по аренде
python housing_budget_model.py --mode rent-sensitivity --out case5
```

**Правила:**

- проценты — в долях (`0.12`, а не `12`);
- доход и расходы — в рублях в месяц;
- `--seed` фиксирует случайность;
- `--out` задаёт папку результатов;
- `--mode` выбирает блок модели.
