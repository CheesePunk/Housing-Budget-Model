# housing_budget_model — модель жилищного бюджета (студия 24 м²)

Экономико-математическая модель распределения бюджета домохозяйства
на жильё и поддержание («бобровая плотина»), сравнение «покупка vs аренда»,
точка безубыточности по доходности инвестиций.

## Что внутри

- `housing_budget_model.py` — код модели и CLI;
- `ARTICLE.md` — полная статья с математикой и результатами;
- `README.md` — этот файл;
- `output/` — графики и CSV после запуска (создаётся автоматически).

## Быстрый старт

```bash
pip install numpy pandas matplotlib scipy
```
```bash
python housing_budget_model.py --mode all --out output --n-paths 300 --seed 42
```

Результаты — в `output/`:
- PNG-графики (траектории, Монте-Карло, сравнение, тепловые карты);
- NPZ с сырыми массивами;
- CSV со сводкой и точкой безубыточности.

## Режимы CLI

| Режим | Что делает |
|---|---|
| `basic` | базовая траектория покупки |
| `mc` | Монте-Карло по стохастическому доходу |
| `compare` | покупка vs аренда на общих шоках |
| `breakeven` | `r_inv*` и `r_inv**` |
| `grid` | тепловая карта по ставке и цене м² |
| `rent-sensitivity` | срез по ставке аренды |
| `all` | всё сразу |

## Основные параметры

| Флаг | Значение по умолчанию | Смысл |
|---|---|---|
| `--area` | 24 | площадь, м² |
| `--price-m2` | 120000 | цена м², ₽ |
| `--down-payment` | 0.20 | доля взноса |
| `--rate` | 0.12 | годовая ставка ипотеки |
| `--years` | 20 | срок |
| `--income` | 80000 | доход, ₽/мес |
| `--maintenance` | 7000 | содержание, ₽/мес |
| `--theta` | 0.45 | порог доли платежей |
| `--rent-m2` | 700 | аренда, ₽/м²/мес |
| `--rent-inflation` | 0.06 | годовой рост аренды |
| `--investment-rate` | 0.08 | годовая доходность инвестиций |
| `--price-mode` | deterministic | `deterministic` или `stochastic` |
| `--n-paths` | 300 | траекторий Монте-Карло |
| `--seed` | 42 | seed для воспроизводимости |
